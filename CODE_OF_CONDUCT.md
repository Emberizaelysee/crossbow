# Code of Conduct

Crossbow adopts the **[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)** as its code of conduct.

In short: be welcoming and respectful. Harassment, discrimination and personal attacks aren't tolerated in issues, pull requests, discussions or any other project space.

## Reporting

Report unacceptable behaviour privately to the maintainer through the contact listed on the maintainer's GitHub profile (a dedicated project address will be added before the first public release). All reports are reviewed promptly and kept confidential.

## Enforcement

Maintainers follow the enforcement guidelines of the Contributor Covenant 2.1 (correction, warning, temporary ban, permanent ban), depending on the severity of the violation.
